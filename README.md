# CMP-400-Crime AI Artifact

Folder Crime AI Scripts has all the scripts and everything else used in the artifact
-------------------------------------------------------------------------------------
In folder Scenes the scene called Final Scene is the scene used for thee artifact
-------------------------------------------------------------------------------------

This project is a short game where the player is able to steal / commit a crime and the npcs will react and alert guards.
The player can steal as much as they want while trying to avoid being caught by guards or bystanders trying to assist in capture.

Created using Unity and c#

Instructions:
- Open the Crime AI application
- play through it at least once and steal as much as you want then head to safe zone.
- a Data.json file will be made when you get caught or escape so once you have played through amke sure to find it in the Crime AI_Data folder.
- Complete the form.

civillians
Red - Alert guards and await questioning
purple - shouting / spreading info
white - gathering
green - protect shopkeep or find and catch player
yellow - run from crime sciene

shopkeeper
grey - back up from player
orange - shout
purple - find guard and alert them
pink - chase player away

Guards 
Blue - every state

Controls:
W,A,S,D for movement.
Mouse movemnet for looking around.
E to "rob" have to be looking at a shopkeeper which you can find behind a "stall". it will stop your movement for a few seconds. has 30 second cooldown.
C to change appearence this will stop your movement for 10 seeconds. has 30 second cooldown.
